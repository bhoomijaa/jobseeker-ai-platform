# 🚀 JobSeeker — AI-Powered Job Application & Resume Analysis Platform

JobSeeker is a full-stack web application that leverages **AI and NLP** to simplify job applications for candidates and streamline hiring for employers through intelligent resume analysis, automated applications, and AI-driven candidate ranking.

---

## 📌 Problem Statement

- 75% of resumes fail ATS screening  
- Manual resume review is slow and biased  
- Job seekers receive little to no feedback  
- Repetitive application forms waste time  

**JobSeeker solves this by automating resume analysis, job matching, and application workflows using AI.**

---

## ✨ Key Features

### 👨‍💼 For Job Seekers
- AI resume analysis with ATS compatibility scoring  
- Skill gap detection and job-match percentage  
- One-click AI-powered application auto-fill  
- Personalized cover letter generation  
- Application tracking dashboard  
- Mock interview question generation  

### 🏢 For Employers
- Job posting and company profile management  
- AI-scored candidate ranking  
- Resume & cover letter preview with insights  
- Bulk application management  
- Hiring analytics dashboard  

---

## 🧠 AI Capabilities

- Semantic job–resume matching
